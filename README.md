## 湉码 / tiancode —— 主打作品

单 exe、数据全在本地、模型与工具可热插拔的 AI 编程工作台。

[![Go](https://img.shields.io/badge/Go-1.22+-00ADD8?logo=go&logoColor=white)](https://go.dev)
[![Release](https://img.shields.io/github/v/release/zhangqi77ok-sys/tiancode)](https://github.com/zhangqi77ok-sys/tiancode/releases/latest)
[![Stars](https://img.shields.io/github/stars/zhangqi77ok-sys/tiancode)](https://github.com/zhangqi77ok-sys/tiancode/stargazers)
[![Platform](https://img.shields.io/badge/Windows-%E6%A1%8C%E9%9D%A2-0078D4?logo=windows&logoColor=white)](https://github.com/zhangqi77ok-sys/tiancode)

- **单 exe**：前端嵌入 Go，双击即用；密钥只存 `%APPDATA%`，数据不出本机
- **模型渠道像换电池**：多渠道池自动选路、多 Key 轮询、五种鉴权方式，兼容各类中转与自建网关
- **工具与扩展热插拔**：MCP 和技能在对话里让 AI 自己安装，保存即热生效
- **稳**：流式回复不丢字、文件命令过审批闸门、上游挂死有看门狗兜底，绝不无声卡住

> 仓库：[zhangqi77ok-sys/tiancode](https://github.com/zhangqi77ok-sys/tiancode)
